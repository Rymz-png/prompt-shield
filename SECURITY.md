# Security policy

PromptShield is an experimental privacy aid and is not a guaranteed data-loss-prevention system.

## Reporting a vulnerability

Please do not publish real credentials or sensitive prompt content in a public issue. Open a report with a minimal reproduction using fake values, or use GitHub's private vulnerability reporting if it is enabled for the repository.

## Scope and limitations

- The scanner is based on patterns and can miss unknown or unusual secrets.
- Website interception depends on third-party user interfaces and can fail after site changes.
- “No known patterns found” must never be interpreted as proof that a prompt is safe.
- Do not use PromptShield as the only safeguard for regulated, enterprise, or high-risk data.
